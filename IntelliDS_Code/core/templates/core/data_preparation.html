Automatic Data Preparation Workflow

After uploading a dataset, IntelliDS performs a comprehensive sequence of preprocessing operations to improve data quality, consistency and usability. Each completed step is documented in the Cleaning Report, allowing you to review every modification before using the prepared dataset for visualization, statistical analysis or machine learning.

Text Cleaning

Removes unwanted spaces, trims extra characters, cleans symbols and standardizes text formatting to improve consistency across categorical data.

Data Type Conversion

Automatically detects numeric values stored as text, converts date columns, restores integer fields and converts boolean values into appropriate data types.

Missing Value Handling

Standardizes missing entries and intelligently fills missing numeric and categorical values using appropriate preprocessing techniques.

Duplicate Detection

Identifies and removes duplicate rows together with duplicate columns that contain identical information, reducing redundant data.

Outlier Processing

Detects extreme numeric values using the Interquartile Range (IQR) method and caps outliers to minimize their influence on analysis and model performance.

Summary & Export

Generates detailed dataset statistics, cleaning summaries, preprocessing reports and provides a downloadable prepared dataset for the next stage of analysis.

Recommended Dataset Structure

  • 1. First row should contain column headers.
  • 2. Keep one structured table per worksheet.
  • 3. Use consistent values within each column.
  • 4. Remove merged cells before uploading.
  • 5. Avoid password-protected Excel files.
  • 6. Remove unnecessary formatting where possible.
  • 7. Keep a backup copy of the original dataset.
  • 8. Ensure the uploaded file is not currently open.
