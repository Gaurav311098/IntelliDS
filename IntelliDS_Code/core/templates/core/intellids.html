IntelliDS Dataset Analysis

Dataset Summary

Displays the total number of rows, columns, memory usage and overall dataset dimensions for a quick overview.

Column Profiling

Profiles every feature by identifying its data type, unique values, missing values, memory usage and sample data.

Data Quality Assessment

Detects missing values, duplicate records, empty columns, constant columns and other quality issues.

Feature Categorization

Automatically classifies features into Numeric, Categorical, Datetime and Boolean data types.

Statistical Analysis

Calculates descriptive statistics including mean, median, minimum, maximum and standard deviation for numeric features.

Target Detection

Suggests possible target columns and determines whether the dataset is better suited for classification or regression tasks.

Recommended Dataset Structure

  • 1. Use the first row as column headers.
  • 2. Store only one dataset per worksheet.
  • 3. Avoid merged cells and complex formatting.
  • 4. Keep consistent data types within each column.
  • 5. Ensure identifier columns are clearly named.
  • 6. Save files in CSV or Excel format.

What Happens After Upload?

  • 1. Dataset preview is generated.
  • 2. Overall dataset statistics are calculated.
  • 3. Column-wise profiling is performed.
  • 4. Dataset quality score is calculated.
  • 5. Missing values and duplicate records are identified.
  • 6. Feature types and statistical summaries are generated.
  • 7. Potential target columns are suggested.
  • 8. Recommendations are provided before data preparation.
